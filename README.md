# react-native-bones

Skeleton loaders measured from your real React Native UI. Render your component with sample data, and `react-native-bones` draws matching bones (one bar per line of text, one block per image) with a single shimmer that stays in sync across the screen.

> **Status:** in development. Not published yet. See [docs/SPEC.md](docs/SPEC.md) for the planned API.
